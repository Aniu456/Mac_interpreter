# WeChat 语音翻译 · 手机免提模式

电脑作为放在手机旁的翻译器。**手机负责微信通话并开启免提；电脑仅使用内建麦克风和扬声器。** 不需要运行 Mac 微信，不需要 BlackHole，也不修改系统默认输入或输出。

## 操作只分两步

1. **听朋友**：点击“听朋友”，电脑听手机免提中的声音，显示朋友的外语原文和中文翻译。
2. **我来说**：点击“我来说”，朋友字幕暂停；对电脑说中文，点击“说完了”。电脑自动翻译并通过内建扬声器播放外语译文，让手机麦克风收进去。

播报期间不识别朋友声音，避免收录电脑自己的译文。播放完成后等待约半秒余音，再自动继续“听朋友”，保留已有字幕。连续对话无需每次手动开启朋友字幕。

底部操作栏固定显示，滚动查看字幕时仍可切换。宽窗口并排显示朋友字幕与中文回复，窄窗口自动上下排列。`⌘ Return` 开始中文或结束当前中文，`Esc` / `⌘ .` 停止全部采集与播报；停止或切换语种后不会自动恢复旧任务。

## 手机与电脑的准备

- 手机接通微信语音通话，打开免提及麦克风，放在电脑旁，让电脑能听清手机、手机也能听清电脑。
- 电脑的语言下拉框读取系统已安装的翻译语言包，只显示与中文双向翻译均已就绪的语言，不再固定语种。波兰语、日语等在当前系统支持且下载完成后会自动纳入。
- 启动或回到应用时会刷新语言列表；也可点击下拉框旁的刷新按钮。正在收听或播报时，请先停止再刷新。刷新会保留仍可用的当前选择。
- 未检测到已下载语言时显示提示，不会默认选中尚未安装的语言。电脑自动选择内建麦克风和扬声器，并在开始收听或播放前重新检查设备。
- 初次使用按系统提示允许麦克风、语音识别，下载翻译语言包及对应系统声音。当前版本不再申请系统音频录制权限。
- 请轮流说话。电脑只在“听朋友”时识别外语，在“我来说”时识别中文。
- 你说中文时手机也可能收到原声。如果只想让朋友听译文，可以在说中文前将手机微信静音，**点击“说完了”前解除静音**，以便手机收到即将播放的译文。应用不能控制手机的静音开关。

不需要改动或卸载已安装的虚拟声卡。电脑播报完成只证明本机播放结束，对方是否听到仍需由实际手机通话确认。

## 播报音色

“播报音色”下拉框读取当前翻译语言可用的系统朗读声音，显示名称、地区和音质；每种语言分别保存选择，也可使用“系统默认”。选择后，“翻译并播放”和“播放译文”都会使用该音色。

在系统设置 → 辅助功能 → 朗读内容中下载新声音后，回到应用或点击语言旁的刷新按钮重新读取；系统发出音色变更通知时也会更新。只列出系统语音 API 向本应用提供的可用声音，因此不保证包含系统设置里的所有 Siri 音色。

## 文字修正与失败重试

- 可直接输入或修改中文，再点“翻译并播放”；此动作会暂停听朋友，播放完自动恢复。
- 已有译文可以点“再次播放”。修改中文后旧译文失效，需重新翻译。
- 识别或翻译失败会保留当前中文；播报失败保留译文，供检查后重试。失败时不会自动循环播报。
- 朋友字幕保留最近六个识别窗口，暂停和恢复不清空；切换语言清空旧字幕。
- 中文每次录入最长约 50 秒；启动等待最多 30 秒。无结果或失败时可以编辑保留的文字。

## 隐私与限制

默认要求本机语音识别。如果设备尚不支持某语言的离线识别，可以在应用菜单 → 设置中开启“允许 Apple 在线语音识别”；开启后音频可能交由 Apple 服务处理。翻译使用系统 Apple Translation，不需要第三方 API Key。

翻译语言包、朗读声音和语音识别资源彼此独立：只下载朗读声音，不代表翻译包已安装。列表依据 Apple Translation 的双向 `.installed` 状态；识别和播报分别匹配系统提供的地区语言，资源缺失时会明确提示。

本应用不保存录音或聊天记录，音频缓冲和字幕只留在内存中。它是轮流说话的分句翻译器，准确度与手机音量、环境声音、语言资源有关。切换到中文或电脑播报期间，朋友的新发言不会被收录。

## 构建与验证

要求 macOS 15+，Swift 6.1+ / Xcode 命令行工具；没有外部 Swift 包。

```sh
./scripts/build-app.sh
open dist/WeChatInterpreter.app
```

请通过 `.app` 启动。默认是供本机使用的 ad-hoc 签名开发包，未公证；可用 `INTERPRETER_SIGN_IDENTITY` 指定开发签名。

```sh
CLANG_MODULE_CACHE_PATH="$PWD/.build/module-cache" \
SWIFTPM_MODULECACHE_OVERRIDE="$PWD/.build/module-cache" \
swift test --disable-sandbox --cache-path .build/cache --scratch-path .build/fix-verification
```

测试覆盖连续三轮对话、播放期间暂停收音、自动恢复字幕、停止和切换语言取消恢复、旧翻译结果拒绝、播放失败重试、字幕保留、权限超时，以及此前崩溃的三声道 PCM 转换。测试使用合成缓冲和模拟回调，不录音、不播报、不拨号，不能替代实际手机收听验收。详细记录见 [验收清单](docs/acceptance.md)。
